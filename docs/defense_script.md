## 三、技术架构（项目经理，1分钟）

> 在技术选型方面，我们采用了前后端分离的架构：

**前端技术栈**：Vue 3 + Vite + ECharts + Pinia + Vue Router  
**后端技术栈**：Flask + SQLAlchemy + MySQL  
**部署技术栈**：Docker + Docker Compose + Nginx + 阿里云ECS

> 我们选择这些技术主要考虑以下几点：
1. Vue 3的组合式API适合构建复杂的单页应用
2. Flask轻量级框架适合快速开发RESTful API
3. Docker容器化部署能够保证开发环境和生产环境的一致性
4. ECharts提供了丰富的可视化图表类型，满足大数据展示需求

## 四、前端技术实现（前端开发工程师，3分钟）

> 大家好，我是前端开发工程师[姓名B]。在项目中，我主要负责前端页面的开发和数据可视化的实现。

### 4.1 大屏数据可视化

> 大屏页面是我们项目的核心展示区域，采用三栏响应式布局：
- 左侧展示高分榜Top10
- 中间展示类型分布和评分分布
- 右侧展示年代趋势和最受关注影片

> 我们使用CSS Grid和Flexbox实现了响应式布局，确保页面在不同分辨率下都能有良好的显示效果。

### 4.2 高级可视化图表

> 我们实现了9种ECharts可视化图表，包括：
- 桑基图：展示类型→国家→年代的流量关系
- 矩阵树：展示类型×国家的片数矩阵
- 词云：展示电影名称的词频分布
- 漏斗图：展示评分分布漏斗
- 日历热力图：展示月度发行片数
- 关系网络图：展示演员/导演合作网络

> 在实现过程中，我们遇到了一些技术难点，比如桑基图的数据匹配问题。后端返回的年代节点name为数字类型，而links中的source/target为字符串类型，导致匹配失败。我们通过在前端统一转换为字符串类型并增加节点存在性验证，成功解决了这个问题。

### 4.3 组件封装

> 为了提升代码复用率，我们封装了多个可复用组件：
- EChart组件：统一封装ECharts图表
- UiCard组件：统一卡片样式
- KpiBar组件：展示核心指标

> 通过组件化开发，我们大大提高了开发效率，也让代码结构更加清晰。

## 五、后端技术实现（后端开发工程师，3分钟）

> 大家好，我是后端开发工程师[姓名C]。在项目中，我主要负责后端API的开发和数据库设计。

### 5.1 API设计

> 我们设计了RESTful风格的API，分为三个模块：
- Dashboard模块：提供大屏数据
- Movies模块：提供电影查询和搜索功能
- Visualization模块：提供高级可视化数据

> API接口遵循统一的请求响应格式，前端可以方便地调用。同时，我们还添加了API Key认证和请求限流功能，确保API的安全性和稳定性。

### 5.2 数据库设计

> 数据库设计采用了维度建模的思想：
- **movie表**：存储电影的完整信息，包括标题、导演、演员、类型、国家、年份、评分等字段
- **聚合表**：包括agg_genre、agg_country、agg_year三个表，存储预计算的统计数据

> 使用聚合表的好处是可以预先计算好统计结果，前端查询时直接获取，大大提升了响应速度，尤其适合大屏实时展示的场景。

### 5.3 桑基图数据生成

> 桑基图数据通过SQL查询生成，从movie表中统计类型→国家→年代的流量数据，返回nodes和links两个数组。为了确保数据的准确性，我们对查询结果进行了去重和过滤处理。

## 十、常见问题预设回答

### 10.1 技术选型类

**Q：为什么选择Vue 3而不是React？**
> A：我们团队对Vue更为熟悉，而且Vue 3的组合式API学习曲线相对平缓，能够更快上手开发。同时，Vue 3的响应式系统和模板语法也非常适合构建数据可视化应用。

**Q：为什么使用Docker部署？**
> A：Docker容器化部署能够保证开发环境和生产环境的一致性，避免"在我机器上能运行"的问题。同时，使用Docker Compose可以方便地管理多个容器服务，简化部署流程。

**Q：为什么设计聚合表？**
> A：直接从电影主表查询统计数据响应较慢，无法满足大屏实时展示需求。使用聚合表可以预先计算好统计结果，前端查询时直接获取，大大提升了响应速度。

### 10.2 功能实现类

**Q：桑基图的数据是如何生成的？**
> A：桑基图数据通过SQL查询生成，从movie表中统计类型→国家→年代的流量数据，返回nodes和links两个数组。前端负责数据的类型转换和节点匹配验证。

**Q：词云的数据来源是什么？**
> A：词云的数据来自电影名称中的关键词，通过分词和词频统计生成。

**Q：日历热力图展示的是什么数据？**
> A：日历热力图展示的是每个月份的电影发行数量，颜色深浅代表片数多少。

### 10.3 团队协作类

**Q：你们是如何进行团队协作的？**
